## Overview

The OnlineGroceries app demonstrates the powerful combination of async/await, the Observable class, and the Fetch API to efficiently fetch and display data in a SwiftUI application. This project focuses on creating a seamless and responsive Product Details Screen for an iOS app using SwiftUI components such as AsyncImage, HStack, VStack, and more.

Features

* Modern Data Fetching: Utilize async/await for handling network requests.

* Observable Class: Leverage Swift's Combine framework to manage state efficiently.

* Fetch API Integration: Fetch real-time product details from an API.

* SwiftUI Components: Enhance the UI with components like AsyncImage, HStack, VStack, and more.

## Technologies Used

SwiftUI

Combine Framework

Async/Await for Networking

Fetch API
